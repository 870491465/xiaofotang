# 小佛堂

一个使用 Cocos Creator 3.8.8 开发的竖屏 2D 静心礼佛小游戏。项目包含角色选择、上香、礼拜、打坐、敲木鱼、功德反馈以及配套音效与角色动作。

## 开发环境

- Cocos Creator 3.8.8
- TypeScript
- 设计分辨率：1080 × 1920

## 运行与构建

1. 使用 Cocos Creator 3.8.8 导入仓库根目录。
2. 打开 `assets/scenes/Main.scene`。
3. 点击“预览”进行本地调试。
4. 在“项目 > 构建发布”中选择 Web Mobile 构建。

构建结果默认位于 `build/web-mobile/`。请通过 HTTP 服务访问，不要直接使用 `file://` 打开。

## 目录说明

- `assets/scripts/`：玩法、界面和角色动作逻辑
- `assets/scenes/`：Cocos 场景
- `assets/art/`：角色、场景及 UI 美术资源
- `assets/audio/`：背景音乐和交互音效
- `settings/`：项目与引擎配置
